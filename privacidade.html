2. Quais Dados Coletamos

2.1. Dados que Você Nos Fornece

  • Cadastro: Nome, email, senha (criptografada)
  • Pagamento: CPF/CNPJ (via Mercado Pago - não armazenamos dados de cartão)
  • Documentos: Textos de contratos, termos ou cobranças que você envia para análise
  • Feedback: Comentários, avaliações ou mensagens de suporte

2.2. Dados Coletados Automaticamente

  • Técnicos: Endereço IP, navegador, sistema operacional, dispositivo
  • Uso: Páginas visitadas, tempo de navegação, cliques
  • Performance: Velocidade de carregamento, erros técnicos
  • Cookies: Identificadores para manter sessão e preferências (veja seção 6)

7. Segurança dos Dados

🔐 Criptografia

HTTPS/TLS em todas comunicações + AES-256 em dados sensíveis

🔒 Senhas

Hash bcrypt com salt único (nunca armazenamos senha em texto)

🛡️ Firewalls

Proteção contra ataques DDoS, SQL Injection e XSS

👥 Acesso Restrito

Apenas equipe autorizada com autenticação 2FA

📊 Monitoramento

Logs de acesso auditados regularmente

💾 Backups

Cópias criptografadas diárias
